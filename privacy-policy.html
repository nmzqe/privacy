隐私政策

更新日期：2026 年 11 月 1 日
生效日期：2026 年 11 月 1 日

本应用由其开发者（以下简称“我们”）开发并提供。本《隐私政策》（以下简称“本政策”）说明本应用如何处理您在使用过程中产生的信息，以及您管理这些信息的方式。请您在使用本应用前仔细阅读并充分理解本政策，其中与您权益密切相关的内容已以加粗形式提示。

在阅读全文前，请您特别注意以下要点：

  • 我们未设立服务器，不运营任何后台服务，不收集、不存储您的个人信息，也无法获取您在本应用中的任何内容。
  • 您的对话、文件、设置和 API Key，以及应用内浏览器的登录状态和 Cookie，都只保存在您的设备上，不会上传给我们。
  • 使用 AI 功能时，相关内容由您的设备直接发送至您自行设置的第三方 AI 服务提供方，不经过我们。
  • 本应用未接入广告、统计分析或崩溃收集类第三方 SDK，不会追踪您。
  • “定位保活”默认关闭。您开启后，本应用使用定位仅为让自己在后台继续运行，不使用、不保存、不上传您的位置，详见《后台保活说明》。
  • 您可以随时在“设置 → 隐私与协议”中撤回同意。

一、本应用的服务方式与本政策的适用范围

本应用是一款 AI 对话客户端。您在本应用中填写您在第三方 AI 服务提供方（以下简称“服务提供方”）处申请的 API Key 后，本应用将您的对话内容发送至该服务提供方，并显示其返回的结果。本应用不提供 AI 模型本身，也不提供账号注册、登录或代充值服务。

本政策适用于本应用对您信息的处理。服务提供方以及您通过应用内浏览器访问的网站，按照其各自的隐私政策和服务条款处理您的信息，不适用本政策。

二、我们不收集您的个人信息

我们不收集您的个人信息，也无法访问您在本应用中输入、上传或产生的任何内容。具体而言：

  • 我们未设立服务器，不运营任何后台服务，本应用不会向我们发送任何数据；
  • 本应用未接入统计分析、崩溃收集或广告类第三方 SDK；
  • 我们不收集设备标识符、位置或使用记录，不对您进行追踪，也不出售您的信息；
  • 我们不会将您设备上存储的信息提供给任何第三方。由您自行选择并发送至服务提供方或网站的内容，见本政策第五部分。

在以下两种情形中，我们可能获得少量信息，但这些信息并非由本应用收集：

  • Apple 提供的信息：Apple 会向开发者提供本应用下载量等汇总统计；如您在 iOS“设置 → 隐私与安全性 → 分析与改进”中开启了“与 App 开发者共享”，Apple 还可能向我们提供本应用的崩溃报告等诊断信息。上述信息由 Apple 收集，并按照 Apple 的隐私政策处理，不包含您的对话等内容，我们无法据此识别您的身份。
  • 您主动联系我们：如您通过电子邮件联系我们，我们将收到您的邮箱地址和您在邮件中提供的内容，仅用于回复和处理您的问题。

三、存储在您设备上的信息

为实现本应用的功能，以下信息存储在您的设备本地，我们无法获取。其中部分内容在您使用 AI 功能时会发送至服务提供方，详见本政策第五部分。

  • 对话内容：您发送的文字、图片和文件，AI 的回复，对话标题，以及 AI 使用工具的过程和结果（包括 AI 查看的网页截图等图片）。
  • 对话文件夹中的文件：您放入的文件，以及 AI 生成的文件。
  • 长期记忆（仅在您开启该功能时）：本应用为您记录的偏好和事实。
  • 设置：服务提供方地址、模型、各项功能开关及权限选择。
  • API Key：保存在 iOS 系统钥匙串（Keychain）中。
  • 用量统计：每次请求消耗的 token 数量，仅在本机统计。
  • 应用内浏览器的网站数据：包括 Cookie、登录状态和网站本地存储，详见本政策第四部分。
  • 闹钟记录：AI 按您的要求设定的闹钟的名称和时间，用于在本应用中查看和删除。

上述信息保存在本应用在您设备上的专属存储空间中，受 iOS 系统的应用隔离机制保护，其他应用无法读取。

您通过本应用新建或修改的提醒保存在 iOS 系统“提醒事项”App 中，并按照您的 iCloud 设置同步，由 Apple 按照其隐私政策处理；本应用设定的闹钟由 iOS 系统管理。

如您启用了设备的系统备份（如 iCloud 备份），备份中可能包含上述数据，该备份由 Apple 按照其隐私政策处理。

四、应用内浏览器的登录信息与 Cookie

应用内浏览器供您和 AI 打开网页。您可以在其中登录网站，以便 AI 在您的账号下浏览和操作。对于这部分信息，我们特别说明如下：

  • 登录信息只保存在您的设备上。 您登录网站后，网站设置的 Cookie、登录状态和网站本地存储，由 iOS 系统的网页组件（WebKit）保存在本应用在您设备上的专属存储空间中。我们未设立服务器，这些数据不会上传给我们；本应用也不会另行备份、导出这些数据，或将其提供给任何第三方。
  • 密码由您本人输入，本应用不保存。 输入密码、填写银行卡信息、输入短信或一次性验证码、提交登录表单等步骤，只能由您本人在浏览器页面中完成，AI 无法代为操作。您输入的账号和密码直接提交给对应网站，本应用不读取、不保存。网站通过系统登录框（HTTP 认证）要求登录时，您填写的账号和密码仅用于当次连接，不会保存。
  • AI 无法获取您的 Cookie 和密码。 本应用不向 AI 提供读取 Cookie 的功能；AI 读取网页时，也不会获取密码框中的内容。AI 浏览网页时，网站会像在普通浏览器中一样收到其自身的 Cookie，用于识别您的登录状态。
  • 两个相互隔离的存储空间。 网站数据分为“外网沙箱”（访问互联网上的网站）和“本地沙箱”（访问您本机或局域网中的地址）两部分保存，相互之间无法读取。AI 运行代码、生成图表和小部件时使用的网页环境不保存 Cookie 或任何网站数据。
  • 重要操作前征得您的同意。 在您登录过的网站上，AI 进行提交、发送、删除、购买等操作前，本应用默认先征得您的同意，您可以在设置中调整。为判断 AI 是否首次向某个邮箱地址发送邮件，本应用会在您的设备上记录已发送过的收件地址，记录时仅保存经过加盐处理的哈希值，不保存地址原文。
  • 您可以随时查看和清除。 您可以在“设置 → Agent 模式 → 浏览器”中查看哪些网站保存了数据，并按网站逐个清除或全部清除；清除后，对应网站的登录状态即失效。卸载本应用也将删除这些数据。

五、发送至您设备以外的信息

在以下情形中，本应用会将相关信息由您的设备直接发送至对应的接收方，不经过我们。我们无法访问该等信息，也不参与其处理。

（一）发送至您自行设置的服务提供方

本应用内置的服务提供方包括 OpenAI、Anthropic、Google（Gemini）、DeepSeek、阿里云百炼、月之暗面（Kimi）、智谱、MiniMax、xAI、OpenRouter、腾讯混元、百度千帆、硅基流动等，您也可以自行填写任何兼容的接口地址。

当您发起对话时，本应用将以下内容直接发送至该服务提供方的接口：

  • 您输入的文字，以及您附带的图片和文件内容；
  • 当前对话此前的内容（对话较长时，可能先压缩为摘要）；
  • 长期记忆（仅在您开启时）和系统提示词；
  • 工具取得的结果，例如 AI 读取的网页内容和网页截图、对话文件夹中的文件内容、代码运行结果，以及 AI 查看的提醒事项和闹钟（图片仅在所选模型支持时发送）；
  • 您的 API Key（置于请求头中，供服务提供方验证您的账号）。

此外，本应用还会在后台向同一服务提供方发送以下请求：

  • 生成对话标题、压缩较长的对话、整理长期记忆，此类请求包含相关的对话内容；
  • 获取模型列表；
  • 探测模型支持的功能，此类请求仅包含测试内容，不包含您的对话。

如您使用联网搜索功能，搜索由该服务提供方的内置工具完成，相关内容同样会发送至该服务提供方。

如您使用图片生成功能，且服务提供方以链接形式返回生成的图片，本应用将从该链接下载图片并显示。该链接由服务提供方提供，下载请求不包含您的对话内容。

上述内容由该服务提供方依照其自身的隐私政策和服务条款进行处理和保存。服务提供方由您自行选择，使用的是您本人的账号和 API Key；我们与服务提供方之间不存在数据共享关系，也无法获取其收到的内容。请您在使用前阅读所选服务提供方的隐私政策和服务条款。

您所选择的服务提供方可能位于中华人民共和国境外。在此情况下，上述内容将基于您的选择传输至境外，并可能适用该服务提供方所在地的法律。我们在您首次使用本应用前，已就“相关内容可能传输至境外服务提供方”向您作出显著提示，并在取得您的同意后方才发送。

（二）发送至您通过应用内浏览器访问的网站

当您在应用内浏览器中自行打开网页，或允许 AI 打开网页、在网页上执行操作时，网站将与在普通浏览器中一样，收到访问请求（如 IP 地址、浏览器信息）、该网站自身的 Cookie 以及所提交的内容，并按照其自身的政策进行处理。

AI 在网页上执行操作前，本应用将按照您在设置中选择的权限征求您的同意。

六、系统权限的使用

本应用在以下场景中使用设备的系统权限：

  • 相机：用于拍照并添加为附件；应用内浏览器中的网页要求拍照或视频验证时也会使用，每次使用前均先征得您的同意。
  • 麦克风：仅在应用内浏览器中的网页要求语音或视频验证时使用，每次使用前均先征得您的同意。
  • 照片和文件：通过 iOS 系统提供的选择器读取，本应用只能读取您选中的内容，不申请完整的相册访问权限。
  • 提醒事项：在 Agent 模式中，按您的要求在“提醒事项”中查看、新建、修改和删除提醒。iOS 对提醒事项仅提供“完全访问”一种授权，授权后本应用可以读取您的全部提醒；AI 每次查看或修改前，本应用均先征得您的同意，您也可以选择以后不再询问。
  • 闹钟（iOS 26 及以上）：在 Agent 模式中，按您的要求设定、修改和删除闹钟。本应用只能管理自己设定的闹钟，无法读取或修改“时钟”App 中的闹钟；每次操作前均先征得您的同意，您也可以选择以后不再询问。
  • 定位：仅在您于“设置 → 定位保活”中开启该功能后申请“使用 App 期间”的定位权限。AI 回答尚未写完而您切换到后台时，本应用使用低精度定位让自己继续运行，回答写完或您回到本应用时停止；本应用不使用、不保存、不上传您的位置。详见《后台保活说明》。
  • 通知：仅在您于“设置 → 定位保活”中开启提醒后申请，用于在本应用不在前台时提示 AI 做完一步或回答写完。通知由 iOS 在本设备上显示，不会发送给我们或任何第三方。

您可以随时在 iOS“设置”中关闭上述权限。

七、信息的保存期限与删除

（一）保存期限

存储在您设备上的数据将保留至您删除为止。

（二）删除方式

您可以在本应用内通过以下方式删除相关数据：

  • 删除对话：在对话列表中删除对应对话，该对话的附件和对话文件夹将一并删除。
  • 删除长期记忆：在“设置 → 记忆与上下文”中操作。
  • 删除服务提供方及其 API Key：在“设置 → 模型配置”中删除对应的服务提供方。
  • 删除网站数据：在“设置 → Agent 模式 → 浏览器”中按网站或全部清除。
  • 删除提醒和闹钟：提醒可以在“提醒事项”App 中删除；本应用设定的闹钟可以在“设置 → Agent 模式 → 闹钟”中删除。
  • 卸载本应用：卸载将删除本应用保存的数据。但 iOS 钥匙串中的 API Key 可能在卸载后仍然保留，建议您在卸载前先在本应用内删除服务提供方。

已发送至服务提供方或网站的数据，需按照其规则向其申请删除。

八、同意与撤回同意

首次启动本应用时，本应用将显示同意页面。您须阅读并同意本政策、《用户协议》和《后台保活说明》后，方可使用本应用。在您同意之前，本应用不会发出任何网络请求。

您可以随时在“设置 → 隐私与协议”中撤回同意。撤回后，本应用将立即停止正在进行的请求；在您重新同意之前，本应用不会再向服务提供方发送任何内容。撤回同意不影响已存储在您设备上的数据，也不影响撤回前已经发送至服务提供方或网站的内容。

九、未成年人保护

本应用不面向 14 周岁以下的儿童。我们无法识别用户年龄，也不主动收集儿童的个人信息。未满 18 周岁的用户，应在监护人的同意和指导下使用本应用。

十、本政策的变更

本政策发生实质变化时，我们将更新本政策载明的日期，并在本应用内提示您重新阅读并同意变更后的政策。
